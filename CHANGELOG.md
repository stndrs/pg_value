# Changelog

## 3.0.0

- Added `Enum` value type with encoder and decoder
- Added `Json` value type with json and jsonb encoder and decoder

## 2.0.0

- Added `Uuid` value type with encoder
- Added UUID decoder
- Added `Hstore` value type with encoder
- Added hstore decoder
- Added decoders for `gleam/time/timestamp.Timestamp`, `gleam/time/calendar.TimeOfDay`, `gleam/time/calendar.Date`
